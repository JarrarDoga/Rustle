Sign in

Rustle signs in with the cookie from a browser where you're already logged in to YouTube Music.

  1. 1Open music.youtube.com in your browser and sign in.
  2. 2Press F12, open the Network tab, then reload the page.
  3. 3Click any request to music.youtube.com and copy the whole Cookie request header.
  4. 4Paste it below.
Stored only on this computer. It stops working if you sign out of YouTube in that browser.
